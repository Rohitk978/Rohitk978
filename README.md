## About me

I'm a data scientist, ML engineer and AI engineer fresher who enjoys solving real-world problems with data. I work across the full pipeline: analysing data, training and tuning machine learning and deep learning models, and building NLP, LLM and agentic AI applications on top of transformer models.

- Building with **Python**, **PyTorch**, **TensorFlow**, **Scikit-Learn**, **Transformers** and **LangGraph**
- Focused on **NLP**, **LLM-powered apps**, **RAG** and **multi-agent systems**
- Strong problem-solving skills and good knowledge of **DSA**
- Ask me about: machine learning models, NLP pipelines, LLM applications, data analysis
